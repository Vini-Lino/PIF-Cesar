Questão 04. Operadores de Atribuição Composta e Precedência — Os operadores de atribuição composta (+=, -=, *=, /=, %=) executam uma operação aritmética e uma
atribuição simultaneamente. Determine quais serão os valores das variáveis a, b, c e d após a execução sequencial completa das seguintes instruções de
inicialização e atribuição em C. Justifique seus cálculos apresentando a ordem de avaliação passo a passo:

int a = 1, b = 2, c = 3, d = 4;
a += b + c; // Valor final de a = 6
a += b + c -> a = 1 + (2 + 3) -> a = 6

b *= c = d + 2; // Valores finais de b e c = (b = 12), (c = 6)
b *= c = d + 2 -> c = 4 + 2 = 6 | b = 2 * 6 = 12 | (agora a = 6, b = 12, c = 6, d = 4)

d %= a + a + a; // Valor final de d = 4
d %= a + a + a -> d = 4 % (6 + 6 + 6) -> d = 4 % 18 -> d = 4

d -= c -= b -= a; // Valor final de d, c e b = (d = 4), (c = 0), (b = 6)
d -= (c -= (b -= a)) | b -= a -> b = 12 - 6 -> b = 6 | c -= b -> c = 6 - 6 -> c = 0 | d -= c -> d = 4 - 0 -> d = 4 | (agora a = 6, b = 6, c = 0, d = 4)

a += b += c += 7; // Valor final de a, b e c = (a = 19), (b = 13), (c = 7)
a += (b += (c += 7)) | c += 7 -> c = 0 + 7 -> c = 7 | b += c -> b = 6 + 7 -> b = 13 | a += b -> a = 6 + 13 -> a = 19 | (Resultado final: a = 19, b = 13, c = 7, d = 4)
